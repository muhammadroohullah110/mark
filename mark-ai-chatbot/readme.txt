AI-powered 3D robot shopping companion. Voice-first, multilingual, friend-first salesman.

== Description ==

Mark AI is an AI-powered shopping companion that transforms online shopping from a lonely experience into a conversation with a friendly robot friend.

Features:
* 3D animated robot character (Three.js)
* Voice-first interaction (speech-to-text + text-to-speech)
* Multilingual support (English + Urdu/Hindi)
* Smart product recommendations from your catalog
* RAG-based page navigation
* Free Edge TTS (no API key needed for voice)
* Full admin dashboard with Arctic Sovereign design
* Multi-store support
* Conversation analytics & tracking
* Easy embed code for external sites

== Installation ==

1. Upload the `mark-ai-chatbot` folder to `/wp-content/plugins/`
2. Activate the plugin through the 'Plugins' menu
3. Go to Mark AI > Settings and enter your backend URL and Groq API key
4. Add your first store in Mark AI > Dashboard
